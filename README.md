# EU CAN Innovate

One-page website for the EU-Canada Digital Bridge Hackathon, an independent initiative at concept stage.

- `index.html` contains the whole page, including styles and the embedded typefaces (Manrope, IBM Plex Sans, IBM Plex Mono, all under the SIL Open Font License).
- `img/` holds the cut-out motifs.

The site is static and has no build step. To deploy it on Vercel, import this repository, choose the "Other" framework preset, leave the build command empty and use the repository root as the output directory.
